# ===========================================================================
# Malabar plant-disease classifier + LangGraph audit workflow
# ===========================================================================
# Two tiers:
#   [core]     — required; the pipeline is verified against exactly these versions.
#   [optional] — the spec-preferred libraries. The code PREFERS them when present
#                and DEGRADES GRACEFULLY when absent, so `python run_pipeline.py`
#                runs with the core tier alone. Uncomment / install to upgrade to
#                the full-fidelity path.
#
# Fallback map (what you lose without each optional lib):
#   timm            -> EfficientNetV2-S. Falls back to torchvision efficientnet_v2_s,
#                      then efficientnet_b0 (cached ImageNet weights).
#   langgraph       -> real StateGraph engine. Falls back to the built-in MiniGraph
#                      (identical node/edge/interrupt/resume/retry semantics).
#   onnx/onnxruntime-> ONNX export + checker + ORT latency benchmark. Falls back to a
#                      torch-CPU benchmark; the ONNX export error is recorded, not fatal.
#   imagehash       -> pHash via the imagehash lib. Falls back to a self-contained
#                      DCT-based pHash (numpy/scipy) — identical dedup behavior.
#   pytorch-grad-cam-> library Grad-CAM++. Falls back to from-scratch hook-based
#                      Grad-CAM++ implemented in explain.py.
#   mlflow / wandb  -> experiment tracking sync. Falls back to the local file tracker
#                      (JSON/CSV/JSONL under runs/<id>/tracking, always on).
# ===========================================================================
